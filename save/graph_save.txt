### 存图
#### 直接存图
```
vector<pair<int,int> >ve;
void add(int x,int y){
    ve.push_back({x,y});
}
```
#### 邻接矩阵
```
int tmp[5005][5005];
void add(int x,int y){
    tmp[x][y]=1;
    //tmp[y][x]=1;
} 
```
#### 邻接表
```
vector<int>ve[100005];
void add(int x,int y){
    ve[x].push_back(y);
    //ve[y].push_back(x);
}
```
